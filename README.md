# Mobile Programming Praktikum

Kumpulan proyek dan tugas praktikum Mobile Programming (Flutter) Semester 5.

## Daftar Modul

| Folder | Topik / Modul | Deskripsi Proyek |
|---|---|---|
| `Modul 1` | Modul 1: Pengenalan Flutter | Proyek pengujian awal Flutter |
| `Modul 2` | Modul 2: Layout Row & Column | Implementasi layout horizontal dan vertikal |
| `Modul 3` | Modul 3: Widget Alignment | Penataan posisi widget dan alignment |
| `Modul 4` | Modul 4: Flexible & Expanded | Responsive layout menggunakan Flexible & Expanded |
| `Modul 5` | Modul 5: Card & SizedBox | UI Card, SizedBox, dan music card |
| `Modul 6` | Modul 6: GridView & ListView | Tampilan GridView, GridView.builder, dan ListView |
| `Modul 7` | Modul 7: Navigasi Halaman | Navigasi PageRoute dan navigasi antar halaman |
| `Modul 8` | Modul 8: Named Route & API | Named routing dan FreeToGame Info app |
| `Modul 9` | Modul 9: State Management | Counter App dan Demo Tasbih (StatefulWidget) |
| `Modul 10` | Modul 10: Mini Game App | Pembuatan Game App interaktif |
| `Modul 11` | Modul 11: GetX State Management | Aplikasi Tasbih digital dengan GetX |

## Cara Menjalankan Proyek
1. Buka salah satu folder modul atau sub-proyek di dalamnya.
2. Jalankan perintah instalasi dependency:
   ```bash
   flutter pub get
   ```
3. Jalankan aplikasi pada emulator atau perangkat fisik:
   ```bash
   flutter run
   ```
